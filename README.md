## 0. 프로젝트 개요
- 성적표를 바탕으로 한 학생간 멘토/멘티 페어링 시스템 설계 및 구축.
- java, spring을 활용해 기존 계약직에서 겪었던 문제를 해결해 봄.


## 1. 요구사항 분석
- 학생은 과목별 성적표를 바탕으로 멘토 또는 멘티를 신청할 수 있다. ( 아무것도 선택 안할 수도 있다. )
- 한명의 멘토는 여러 명의 멘티를 받아 줄 수 있다. 한 명의 멘티는 오직 한명의 멘토와 매칭될 수 있다.
- 멘티는 멘토를 선택할 수 있다.
- 시스템은 “priority rule”을 따라서 멘토를 추천해 줄 수 있다.
    - 현시점 priority rule
        - 특정 과목의 점수 차이
        - 종합 점수 차이
        - 생년월일 순

## 2. 주요 기능
- 정책에 따른 멘토 추천 서비스 (과목 최대 점수차 / 총점 차이 / 라이벌형 정책 등 생각 중)
- 학생 선택 하에 멘토/멘티 역할을 정하고서 멘토링 신청

## 3. 기술 스택
- SpringBoot, JPA, Spring Data JPA, Spring MVC
- Thymeleaf

## 4. 프로젝트 구조

```text
mentor_pairing/
├── controller/         # HTTP 요청 처리 및 화면 연결
├── domain/             # 엔티티, Enum 및 핵심 도메인 모델
├── recommendation/     # 멘토 후보 추천 로직
│   └── policy/         # 추천/매칭 정책
├── repository/         # 데이터 접근   
└── service/            # 비즈니스 로직 및 트랜잭션 관리
```

## 5. 실행방법
```text
./gradlew build         # 이후 나온 jar 파일 실행
java -jar build/libs/mentor-pairing-0.0.1-SNAPSHOT.jar

# 이후 localhost:8080에서 확인
```
